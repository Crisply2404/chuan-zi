# 寻路补充词库研究

日期：2026-10-14，Asia/Shanghai。使用 Skill：research。

## 已核实的补充来源

[万象词库 RIME-LMDG](https://raw.githubusercontent.com/amzxyz/RIME-LMDG/5da3670129a82aeb0b20c3081d48c4f05ebd794b/README.md) 的简体基础词库已收录“寻路”，完整记录为 `寻路 xún lù 471`。声调标记对应 `xun2 lu4`，能够提供游戏需要的完整词语读音。该项目持续维护词语、带声调拼音和词频，同时把医学、化学、药品、地名及人名词库作为独立文件提供。[S1][S2][S4]

建议优先把万象作为新增词语的候选及完整读音来源。相对于 jieba，它直接提供词语级声调，专业分类文件也便于限定收录来源。这些特点适合当前游戏的声母、韵母与声调条件；jieba 继续承担现有常见程度参考。[S1][S2][S6]

万象的基础词库面向输入法，没有释义、普通词语身份标签或逐项词典引证。基础文件中仍存在本项目明确排除的表达。因此，本轮核实的是更方便补充词形与读音的来源；新增有效答案仍需确认独立词语身份和日常使用范围。本次没有核实到已经同时排除全部口语组合与专业名称、提供完整读音和释义、且已收录“寻路”的完整游戏词库。[S1][S2][S5][S6]

## 固定版本与真实下载记录

核查版本：`5da3670129a82aeb0b20c3081d48c4f05ebd794b`，仓库默认分支为 `wanxiang`。本轮直接下载固定版本的 README、完整 LICENSE、简体基础词库 `dicts/jichu.dict.yaml` 和医学分类文件；本项目词库及已有 jieba 资料一并用于收录核查。[S1][S2][S3][S4][S5]

基础文件大小为 44,565,641 bytes，SHA-256 为 `491a80628719f6eeabf7d1eb040a86c872175736a6a6c63f702f6f87e32230a8`。按照文件真实 TSV 数据部分，使用现有 `csv-parse` 完整读取，得到 1,410,769 条记录、1,410,767 个唯一词形。唯一词形均为二至九个汉字，其中 1,336,817 个没有出现在当前游戏的 89,431 个有效答案中。差集数量表示尚未审核的候选，实际新增数量需要依据最终收录结果计算。[S2][S5]

“寻路”在固定基础文件第 136,855 行出现一次，读音为 `xún lù`，权重为 `471`。词形已经为简体，收录这一项无需繁体转换。拼音字段应为声母 `x`、`l`，韵母 `un`、`u`，声调 `2`、`4`；当前数据文件尚无这一项。[S2][S5][S6]

官方 README 说明词频经过归一化处理，字段参与输入法候选排序。因此 `471` 不能直接与 jieba 的词频 `9` 比较为中文实际使用次数，也不能单独证明游戏收录资格。[S1][S2][S6]

## 许可与使用条件

RIME-LMDG 的完整 LICENSE 为 Creative Commons Attribution 4.0 International，即 CC BY 4.0。该公开许可授予全球、免费使用权，允许复制、分发、修改与商业使用，适用于网页游戏和带广告的微信小程序。[S3]

发行所用资料时，需要保留作者或项目署名、来源链接、许可说明、免责声明，并标明筛选、转换与修改。单独保持来源文件和修改资料的许可说明，现有 CC-CEDICT 派生资料继续遵守项目原来的 CC BY-SA 4.0 要求。[S3][S6]

本轮许可核查针对官方发布的 `dicts/jichu.dict.yaml` 与其公开 LICENSE。仓库 README 描述了语料类型及校对方式，但未逐项提供最初语料引用和释义引证；相关词语的独立身份需要另行核查。官方所述 AI 辅助筛选与人工校对属于维护方法，不能替代游戏对最终答案的审核。[S1][S2][S3]

## 收录前需要确认的资料

有效补充项应记录词形、认可的完整读音、普通词语或成语分类、来源版本和审核依据，继续遵循 `data/policy.json` 的明确排除设置。万象的其他分类文件用于范围核查；普通答案候选限定于已经审核的基础词条。[S6]

新增词语读音使用同一套完整拼音参与全部条件，多音词按完整读音集合处理。新增所用汉字还需要检查项目字形与真实笔画映射，并由同一生成词库供草稿、提交、提示生成及电脑选择使用。若最终采用资料缺少完整读音、来源或必要字段，数据构建立即抛出错误。[S6]

“寻路”的词形及 `xún lù` 读音已在这套公开资料核实。本次未取得适合直接复用的释义与词典独立词条证明，产品词库保持当前内容。研究证据和统计程序位于 `.research/xunlu-supplement-2026-10-14/`；执行 `node .research/xunlu-supplement-2026-10-14/audit.mjs` 可复核完整基础文件与当前答案差集。[S2][S5]
